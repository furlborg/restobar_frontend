# Logos de Métodos de Pago / Payment Method Logos

Puedes colocar aquí tus imágenes oficiales para cada método de pago. El sistema las detectará y cargará automáticamente en lugar de los vectores por defecto.

### Nombres de archivo soportados:
- **Yape:** `yape.png`, `yape.svg`, `yape.webp`
- **Plin:** `plin.png`, `plin.svg`, `plin.webp`
- **Tunki:** `tunki.png`, `tunki.svg`, `tunki.webp`
- **Tarjeta:** `tarjeta.png`, `visa.png`, `mastercard.png`, `card.svg`, etc.
- **Efectivo:** `efectivo.png`, `cash.png`, `efectivo.svg`
- **Depósito Bancario:** `banco.png`, `deposito.png`, `transferencia.png`
- **Cualquier otro método personalizado:** Guarda la imagen con el mismo nombre que creaste en la configuración (ejemplo: si creaste un método llamado "Agora", guarda `agora.png`).

### Formatos aceptados:
`.png`, `.svg`, `.webp`, `.jpg`
Recomendado: Imágenes transparentes cuadradas (ej. 64x64px o 128x128px) o vectores `.svg`.
